Description
Developed a Resume Screening and Job Matching System that automatically compares resumes with Job Descriptions using keyword-based analysis. The application identifies relevant skills and qualifications, calculates a matching score, and helps recruiters quickly shortlist suitable candidates. The project is implemented entirely using built-in programming features, without external packages, libraries, or third-party APIs.
